# 📊 Data Scientist — Latihan & Eksplorasi Data

Kumpulan **latihan analisis data** dan **Exploratory Data Analysis (EDA)** menggunakan **Jupyter Notebook** dan Python. Berisi eksplorasi beberapa dataset, termasuk data harga minyak mentah Brent.

---

## 📓 Daftar Notebook

| Notebook | Isi |
|---|---|
| `latihan1_EDA.ipynb` | Eksplorasi data awal (Exploratory Data Analysis) |
| `latihan2.ipynb` | Latihan analisis data |
| `latihan3.ipynb` | Latihan analisis data |
| `latihan4.ipynb` | Latihan analisis data |
| `latihan5.ipynb` | Latihan analisis data |

## 📁 Dataset

| File | Keterangan |
|---|---|
| `BrentOilPrices.csv` | Data historis harga minyak mentah Brent |
| `train.csv` / `test.csv` | Dataset latih & uji |
| `tv.csv` | Dataset tambahan |
